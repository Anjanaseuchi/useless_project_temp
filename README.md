### Project Description
Charger Guilt is a hilariously passive-aggressive web application designed to shame you into leaving your phone alone while it's plugged in. Utilizing browser APIs to track device motion and charging status, it relentlessly bombards you with funny audio clips the second you pick up your charging phone or try to use it before it reaches full battery.

### The Problem (that doesn't exist)
Modern humans suffer from acute separation anxiety whenever their phone is tethered to a wall outlet. Instead of letting the poor device charge in peace, we constantly pick it up to scroll through feeds, check notifications, or stare blankly at the lock screen—thereby ruining battery health and defying all logic of patience.

### The Solution (that nobody asked for)
A chaotic web-based intervention tool that weaponizes guilt and comedy. If your phone is plugged in and detects movement or usage before hitting 100%, it triggers a non-stop loop of goofy, obnoxious, or dramatic sound effects. The audio will not stop playing until you put the phone back down and let it charge in peace!

⚡ Charger Guilt – Smart Phone Charging & Usage Awareness Web App

Charger Guilt is a fun and interactive web application designed to encourage users to keep their phones aside while charging. The application monitors the phone's battery level and charging status and provides funny character reactions and audio responses when the user interacts with the phone during a charging session.

The project is developed using HTML, CSS, and Vanilla JavaScript. It uses browser-based features such as the Battery Status API, Device Motion API, Page Visibility API, and HTML5 Audio to create an interactive experience.

🔋 Key Features:

Real-time battery percentage display
Charging status detection
“Just Plugged In” charging session
Phone usage/activity detection
Battery-level-based funny audio responses
Sequential audio escalation
Interactive emoji/character reactions
Special “Fully Charged” state
Funny sound effects and voice clips
Fully frontend-based web application
🎯 Objective:
To create a simple, entertaining, and interactive way to remind users to let their phones rest while charging.

Technologies Used: HTML5 | CSS3 | JavaScript | Battery Status API | Device Motion API | Page Visibility API | HTML5 Audio | GitHub Pages*
